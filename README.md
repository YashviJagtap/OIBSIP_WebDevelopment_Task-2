# OIBSIP Web Development Task 2 - Personal Portfolio

## Objective
The objective of this project is to create a personal portfolio website that showcases skills, projects, and contact information using HTML and CSS.

## Tools & Technologies Used
- HTML
- CSS
- Visual Studio Code
- Live Server

## Steps Performed
1. Created the homepage introducing the developer.
2. Added sections like About Me, Skills, Projects, and Contact.
3. Styled the portfolio using CSS for better design and layout.
4. Added hover effects and smooth scrolling.
5. Tested the website using Live Server.

## Outcome
A clean and responsive personal portfolio website that highlights personal information, skills, and projects.
